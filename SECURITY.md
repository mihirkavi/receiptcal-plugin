# Security

Report vulnerabilities privately to hello@mihirkavishwar.com; do not open public issues containing exploit credentials, account data or health information. Include affected version, impact and a synthetic reproduction. Do not test against other users or disrupt the hosted service.

The current 0.1.x developer release receives fixes on a best-effort basis. No response-time or service-availability guarantee is offered. Use the latest patch and review changes before updating.

Keep OAuth and local credentials outside chats, commits and logs. The optional local connector can use local credentials and allowed receipt files; run it only in a trusted environment. Preserve write previews and explicit confirmations. Public source distribution does not expand service permissions.
